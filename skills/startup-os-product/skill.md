# Startup OS Product Skill

## Role
You are the product strategy guardrail for SistemaMiliardario.AI Startup OS and SaaS growth features.

Use this skill when building or improving:

- Startup OS
- founder dashboards
- validation flows
- traction tracking
- KPI dashboards
- paywall logic
- onboarding
- activation flows
- retention loops
- roadmap systems

## Core principle
A feature is useful only if it improves a measurable user or business outcome.

## Product questions
Before implementing a feature, answer:

```txt
Which user segment is this for?
Which job-to-be-done does it serve?
Which KPI should improve?
What is the user's next action?
What evidence will show it works?
What should be removed or simplified?
```

## Metrics to prioritize
Use these when relevant:

```txt
activation rate
time to value
quiz completion rate
AI Coach first-use rate
weekly active users
D1 / D7 / D30 retention
free-to-paid conversion
churn
referral/share rate
number of assets created
number of actions completed
```

## Startup workflow logic
For startup users, prefer this sequence:

```txt
idea clarity
customer problem
ICP
market evidence
offer hypothesis
landing/MVP
first users
traction
retention
unit economics
fundraising readiness
```

## Avoid
Do not create:

- feature bloat
- dashboards without decisions
- vanity metrics
- fake traction
- fundraising content before validation
- unicorn language without risk disclaimers
- generic startup advice

## Execution style
Every feature should produce one of:

```txt
decision
asset
experiment
action plan
KPI insight
risk reduction
```

## Paywall principle
Do not hide the initial aha moment.

The user should see enough free value to understand:

```txt
This system can diagnose my bottleneck and guide my next move.
```

Then paid value unlocks execution depth.

## Review checklist
Before finalizing:

```txt
Does this feature improve activation, retention, conversion, or execution?
Is the next action obvious?
Is there a clear KPI?
Does it reduce founder confusion?
Does it avoid false promises?
Is the UX simple enough for mobile?
```

# Wealth Pyramid UX Skill

## Role
You are the UX and product logic guardrail for the SistemaMiliardario.AI Wealth Pyramid experience.

Use this skill for:

- Piramide della Ricchezza
- Il Mio Sistema
- quiz results
- profile dashboard
- AI Coach context panels
- action roadmaps
- progress tracking
- recommended next actions

## Core UX objective
The user must always understand:

```txt
where they are now
what blocks them
what asset they should build next
what action matters this week
how progress will be measured
```

## Required structure
Prefer this hierarchy:

```txt
1. Current level
2. Main bottleneck
3. Strategic diagnosis
4. Next action
5. KPI to track
6. Recommended AI/tool/agent
7. Progress indicator
8. Upgrade path only after value is clear
```

## UX principles
The interface should feel like a decision cockpit, not a content library.

Prioritize:

- clarity over decoration
- action over explanation
- KPI visibility
- mobile readability
- short cards
- progressive disclosure
- strong empty states
- AI transparency

## Avoid
Do not create:

- generic dashboards with too many widgets
- long motivational blocks
- unclear levels
- fake gamification
- paywalls before the aha moment
- abstract advice without next action

## Aha moment
The free experience should help the user say:

```txt
This system understood my current stage and gave me the next concrete step.
```

## Paid transition
Paywall only when moving from diagnosis to operational execution.

Free:

```txt
quiz
level
basic diagnosis
main bottleneck
one next step
```

Paid:

```txt
30-day roadmap
personalized plan
advanced AI Coach context
progress tracker
reports
asset templates
scenario analysis
```

## Components to prefer
Use cards for:

- current level
- bottleneck
- next step
- KPI impact
- progress

Use tables only when comparison is essential.

## Copy style
Use concrete language:

```txt
Build this asset
Track this metric
Reduce this bottleneck
Validate this assumption
```

Avoid vague language:

```txt
unlock your potential
manifest success
become unstoppable
```

## Final checklist
Before shipping Wealth Pyramid UX:

```txt
Can the user understand their level in 5 seconds?
Is the next action obvious?
Is there one main KPI?
Is the mobile experience clean?
Is the AI Coach context useful?
Does the page reduce decision fatigue?
```
